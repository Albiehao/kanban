# Stress App

SwiftUI + HealthKit based personal physiological stress monitoring app.

## Core flow

Apple Health HRV (SDNN) → 30-day personal baseline → ln transform → Z-Score → 0–100 stress score.

## Requirements

- iOS 17+
- Xcode 16+
- HealthKit capability enabled

This repository is a clean rebuild of the previous Kanban project. Historical code remains available in Git history and on the main branch until this rebuild is reviewed and merged.
